# Preserved prerequisite contracts and standalone qualification

This source-only product originates at reviewed umbrella source
`f150b28cb25ad55a99b37b06fa0ddc989f3428d9`. Active 0.2.0 / v2 updates only the
shared-core/profile admission to exact a794e3b; native.py and lora.hndl retain
reviewed source bytes. Prior 0.1.0 / v1 is not relabeled. The prior installed 43-case proof
remains upstream; prior run logs and environment-path receipts are not exported.
New standalone installed receipts are delivered separately to root.

The native response remains `[1,image_tokens,64]`. Preflight probes the existing
`continuous_field` rank gate with unchanged geometry, preserving its actual 4D/5D
rejection. No invented domain, native admission or training registration exists.
Wrong PG versions/source bytes report `FluxSourceMismatch` with the original
cause. Tests pass a real tiny model and preserve its tensors, gradients/flags,
modes, existing hooks and CPU Torch RNG across refusal. Both constructors fork
and restore CPU Torch RNG on success/failure with a private sequential bank stream.

Standalone tests retain the historical matched-weight outputs/input/all-parameter
VJP checks using the one separately staged, hash/Git-blob-verified public reference
specified in `tests/historical-reference.json`. They also check OFF/raw outputs,
raw nn.Module weight roundtrip, lack of entrypoints/umbrella imports, source-lock
relocation and synthetic legacy-container refusal before backend resolution.
These do not qualify EMA, shared resume/export, native training or actual old
model checkpoints. All model API fixtures are randomly initialized tiny native
Flux models on CPU; there are no weights, GPU jobs or quality claims.

Portable installation/staging/test commands are in README.md. Wheel and sdist
must be installed and tested from outside the source tree with no umbrella
checkout on Python's path. All five installed payload files must match source
bytes. The sdist includes this document, provenance and the external-reference
manifest/script, but never the downloaded test reference or test run outputs.

The complete recursive 50-file core payload check compares `sources.json:core_sources`
against every file beneath installed `particle_sliders/`, excluding only
`__pycache__` paths and `.pyc`/`.pyo` bytecode. It includes 35 Python files, 12 JSON
files, 2 HNDL graphs and LICENSE. Added nested data/unknown suffixes, missing files
and changed bytes all reject. Distribution metadata outside the package root is
not part of that payload dictionary. Historical manifests are identity data;
checking them does not admit their source profiles. HyperGAN/HNDL build/runtime
provenance is verified separately by verified_builder.
